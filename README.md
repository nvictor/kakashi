# Kakashi

Your command reference, one shortcut away.

Keep task recipes as YAML files in a folder. Search them from the menu bar, fill in shared inputs once, and copy each step, ready to paste into your terminal.

- Quick search from the menu bar or with **Option-Shift-Space**.
- Arguments are quoted for you. Secret inputs stay hidden and leave the clipboard after 60 seconds.
- Local and read-only. Kakashi never runs a command.

To write your own workflows, see [Workflow authoring](docs/workflow-authoring.md) and the [examples](examples).

Requires macOS 14 or later and Apple Silicon.
